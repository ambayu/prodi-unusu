# Identitas SIN

Letakkan logo resmi SIN di `logo-sin.png`, logo universitas di `logo-unusu.png`,
dan favicon PNG di `favicon.png`. Gunakan PNG transparan beresolusi memadai.
Komponen otomatis memilih file yang tersedia; tidak perlu mengedit setiap layout.

`sin-mark.svg` adalah monogram sementara (bukan logo resmi), sekaligus fallback
favicon. Logo UNUSU menggunakan `public/assets/pai/logo-unusu.jpg` bila PNG belum
tersedia. Aset lama tetap disimpan. Path dapat diatur di `config/branding.php`.
